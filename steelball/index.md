## 1. 기본 원칙과 적용 범위

`스틸볼런`의 운영 주체인 릴리에스앤씨(공개 개발자명: 릴리게임즈, 이하 “운영자”)는 이용자의 개인정보를 중요하게 생각하며 개인정보 보호법 등 관련 법령을 준수합니다.

이 방침은 다음 배포 환경에 적용됩니다.

- Google Play에서 배포하며 게임 웹 자산을 앱 패키지에 포함한 Android WebView 앱
- 앱인토스에서 제공하는 게임 미니앱
- 개발 및 품질 검증을 위한 브라우저 버전

Google Play Android 버전은 Google Mobile Ads(AdMob) SDK와 Google User Messaging Platform(UMP)을 사용합니다. UMP는 앱을 실행할 때 동의 상태를 갱신하고 필요한 지역에서 동의 양식을 표시하며, **UMP가 광고 요청을 허용한다고 확인한 뒤에만** 광고를 요청합니다. 동의 정보를 확인할 수 없으면 광고를 요청하지 않고 게임만 계속합니다.

Firebase Analytics 웹 SDK는 Firebase 설정이 포함된 배포본에서 동작하며 게임 이용 이벤트를 Google에 전송합니다. 앱인토스 버전에는 AdMob SDK가 포함되지 않습니다.

서비스에는 회원가입, 로그인, 인앱결제, 채팅, 이용자 게시물, 클라우드 저장, 운영자 자체 서버가 없습니다.

Google Play, Google, 토스, GitHub 등 플랫폼 또는 SDK 제공자가 자신의 서비스 운영을 위해 독립적으로 처리하는 정보에는 각 제공자의 개인정보처리방침이 함께 적용됩니다.

## 2. 개인정보 처리 요약

| 구분 | 처리 내용 |

| 앱 내 계정·로그인 | 없음 |
| 운영자 자체 서버로 보내는 정보 | 없음. 운영자는 자체 API 서버·계정 시스템·클라우드 저장소를 운영하지 않음 |
| Google Play 광고 | AdMob 배너와 전면 광고. UMP가 허용한 뒤에만 요청 |

| 광고 관련 자동 처리 | 광고 식별자(AAID), IP 주소에서 추정되는 대략적 위치, 기기·앱 정보, 광고 요청·노출·상호작용, 동의 신호 |
| 광고 동의·선택 | UMP가 요구하는 지역에서 동의 양식을 표시하고, 이후 이용자가 다시 열 수 있는 개인정보 선택 항목을 제공 |

| 분석 관련 자동 처리 | Firebase가 Analytics 제공을 위해 처리하는 기기·브라우저·앱 정보, 세션·진단 정보 |
| 원격 오류 수집 SDK | 사용하지 않음(Crashlytics 등 없음) |
| 인앱결제 | 없음. 게임 내 골드는 플레이로만 획득 |
| 위험 권한 | 위치, 연락처, 사진, 카메라, 마이크, 저장소 권한을 요청하지 않음 |
| 로컬 저장 | 최고 기록, 보유 골드, 해금·장착 외형, 하트와 회복 기준 시각, 튜토리얼 완료 여부, 음향 설정, 조작 안내 표시 여부, UMP 동의 상태 |
| 이용자가 직접 보내는 문의 | 발신 이메일 주소, 문의 내용과 자발적으로 첨부한 정보 |
| 개인정보 판매 | 하지 않음 |

비개인 맞춤 광고 또는 제한된 광고도 광고 제공, 빈도 제어, 보안과 부정행위 방지를 위해 IP 주소, 기기 정보 또는 진단 정보 일부를 처리할 수 있습니다. 따라서 “비개인 맞춤 광고”가 모든 데이터 처리가 중단된다는 뜻은 아닙니다.

## 3. Google Play Android 앱의 AdMob 처리

광고가 활성화된 Google Play 버전은 화면 하단에 적응형 AdMob 배너를 표시할 수 있습니다. 배너는 **자유 굴리기 화면과 외형 상점에만** 두고, 기록 주행·18m 연습 코스·결과 팝업에서는 내립니다. 배너 높이는 SDK가 알려 준 값만큼 게임 화면에서 미리 비워 두므로 조작 버튼이나 게임 요소를 가리지 않습니다. 광고를 받지 못하면 비워 둔 공간을 즉시 회수합니다.

전면 광고는 결과 화면에서 이용자가 `다시 굴리기`를 누른 전환에서만 후보가 됩니다. 실제 노출 이후 최소 3판, 실제 조작 시간 누적 조건과 전체 화면 오버레이 쿨다운을 모두 만족해야 하며, 첫 실행 연습 코스와 처음 두 판에서는 표시하지 않습니다. 광고를 불러오지 못하면 광고 없이 즉시 다음 주행으로 넘어갑니다.

앱은 광고 시청을 조건으로 게임 보상이나 진행을 제공하지 않습니다(보상형 광고 없음).

## 4. 광고 동의와 개인정보 선택

Google Play 버전은 실행 시 UMP로 동의 상태를 갱신합니다. 동의가 필요한 지역에서는 동의 양식을 표시하고, 이용자의 선택에 따라 개인화 또는 비개인화 광고가 제공됩니다. 동의 정보를 가져오지 못하거나 동의가 확인되지 않으면 앱은 **광고를 요청하지 않습니다.**

UMP가 개인정보 선택 항목을 요구하는 지역에서는 이용자가 나중에 다시 선택을 바꿀 수 있는 진입점을 제공합니다. 해당 항목을 요구하지 않는 지역에서는 표시되지 않습니다.

## 5. Firebase Analytics

Firebase 설정이 포함된 배포본은 Firebase Analytics 웹 SDK로 다음 이벤트를 전송합니다.

| 이벤트 | 전송 값 |
| --- | --- |
| `app_open` | 튜토리얼 완료 여부 |
| `run_end` | 점수, 주행 거리(m), 이어하기 여부, 경과 시간(초) |

모든 이벤트에는 앱 ID, 앱 버전, 세션 ID, 배포 모드가 공통으로 붙습니다. 세션 ID는 앱을 실행할 때마다 새로 만드는 임의 값이며 기기·이용자를 지속적으로 식별하기 위한 값이 아닙니다. 운영자는 이름·이메일·전화번호 같은 식별 정보를 이벤트에 넣지 않습니다.

## 7. 운영자가 직접 입력받지 않는 정보

앱에는 이용자가 개인정보를 입력하는 화면, 계정 생성, 채팅, 결제 또는 이용자 간 상호작용 기능이 없습니다. 운영자는 이름, 생년월일, 성별, 이메일, 전화번호, 계정 정보, 정확한 위치, 주소록, 사진·동영상, 카메라·마이크 입력, 결제·금융 정보, 민감정보를 입력받거나 저장하지 않습니다.

다만 AdMob·UMP·Firebase Analytics는 제2조·제8조에 적힌 범위에서 광고 식별자, IP 주소, 기기·앱 정보, 동의 신호와 이용 이벤트를 처리할 수 있습니다. 이는 운영자가 위 정보를 게임 입력 화면에서 받는 것과 구별됩니다.

## 11. 보유 기간과 삭제 방법

운영자 자체 서버에는 게임 진행 정보나 이용자별 프로필을 저장하지 않습니다. 기기에 저장된 값은 다음 방법으로 삭제할 수 있습니다.

- Google Play Android 앱: Android 설정에서 `스틸볼런`의 저장공간·앱 데이터를 삭제하거나 앱을 제거
- 앱인토스 버전: 토스 앱의 해당 저장소 초기화 또는 토스 앱 제거
- 브라우저 버전: 해당 사이트의 저장 데이터 또는 `localStorage` 삭제

AdMob·UMP·Firebase Analytics가 처리하는 정보의 보유·삭제는 Google의 정책과 이용자 제어 수단을 따릅니다.

## 12. 이용 대상 연령

앱은 만 13세 이상 이용자를 대상으로 합니다. 만 13세 미만 아동을 대상으로 설계하거나 운영하지 않으며, 아동에게 개인정보를 입력하도록 요구하지 않습니다. 만 14세 미만 이용자가 지원 문의를 해야 하는 경우 법정대리인이 대신 문의해야 합니다.

- 앱 내 개인정보 입력 기능과 운영자 계정을 두지 않음

- UMP가 광고 요청을 허용하기 전에는 광고를 요청하지 않음(동의 정보 조회 실패 시에도 요청하지 않음)
- 광고 앱 ID는 네이티브 설정, 광고 단위 ID는 빌드 구성으로만 주입하고 분석 이벤트에 넣지 않음
- 위험·민감 Android 권한을 요청하지 않고 cleartext 통신을 허용하지 않음
- 새 SDK나 네트워크 기능을 도입하기 전에 권한, 동의와 데이터 흐름을 다시 검토
