# Prism Breaker 개인정보처리방침

[English](en/)

- 최초 작성·적용: 2026년 9월 28일
- 공개 개발자: 릴리게임즈 / 운영 주체: 릴리에스앤씨
- 문의: [lilygames@lilysnc.com](mailto:lilygames@lilysnc.com)
- 홈페이지: https://lilygames.lilysnc.com
- 서비스: Prism Breaker (Android 패키지: com.lilysnc.prismbreaker)

## 1. 적용 범위

이 방침은 Google Play용 Prism Breaker 앱과 웹 버전(https://prismbreaker.pages.dev)에 적용됩니다. 다른 게임 포털에 올라간 배포본은 해당 포털의 방침도 함께 적용됩니다.

## 2. 게임 진행과 기기 저장

판 진행도, 별, 코인·아이템, 이어서 할 판, 본 안내·컷씬 기록, 언어·소리 설정을 기기에 저장합니다. 앱은 앱 전용 웹 저장소(localStorage), 웹은 브라우저 localStorage를 사용합니다. 이 데이터는 서버로 전송되지 않으며 운영자가 볼 수 없습니다.

코인은 게임 내 재화이며 현금 환전·결제 기능이 없습니다. 회원가입·로그인·실명·연락처가 필요하지 않습니다.

## 3. 광고·분석·서버

현재 배포본에는 광고 SDK, 분석 도구, 자체 서버, 리더보드, 결제가 없습니다. 게임 파일은 앱 안에 들어 있어 인터넷 없이도 실행됩니다. 광고나 분석을 추가하는 경우 그 배포본 출시 전에 이 방침과 스토어 고지를 먼저 갱신합니다.

## 4. 공유와 기기 기능

결과 화면의 ‘자랑하기’를 누르면 기기의 공유 창에 게임 결과 문구를 넘깁니다. 어디로 보낼지는 이용자가 고르며, 공유된 내용은 선택한 앱의 방침을 따릅니다. 진동(햅틱)은 기기 안에서만 동작합니다. 앱은 인터넷 권한 외의 권한을 요청하지 않으며 위치·연락처·사진·카메라·마이크에 접근하지 않습니다.

## 5. 처리 목적과 이용자 선택

기기 저장은 게임 진행을 이어가기 위한 것입니다. 설정 화면에서 언어와 소리를 바꿀 수 있고, 앱 데이터를 지우거나 앱을 삭제하면 저장된 진행이 모두 삭제됩니다.

## 6. 제공자와 처리 위치

| 제공자 | 역할 |
|---|---|
| Google | Google Play 앱 배포, 문의 이메일 서비스 |
| Cloudflare | 웹 버전 배포(접속 보안·로그) |
| GitHub | 개인정보처리방침 페이지 호스팅 |

각 제공자의 글로벌 인프라에서 국외 처리가 발생할 수 있으며, 세부 사항은 해당 제공자의 정책을 따릅니다.

[Google 정책](https://policies.google.com/privacy) · [Cloudflare 정책](https://www.cloudflare.com/privacypolicy/) · [GitHub 정책](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)

## 7. 보유·삭제

기기 데이터는 이용자가 앱 데이터를 지우거나 앱을 삭제할 때까지 유지됩니다. 운영자는 게임 진행 데이터를 보관하지 않습니다. 문의 이메일은 문의 처리 완료 후 30일 이내 삭제하되, 법령상 보관 의무가 있는 경우 필요한 기간 보관합니다.

## 8. 이용자 권리·아동

이용자는 적용 법령에 따른 열람, 정정, 삭제, 처리 제한 및 동의 철회 권리를 행사할 수 있습니다. 문의는 위 이메일로 접수하며 적용 법정 기한 내 처리합니다. 대한민국 개인정보침해 신고센터(118), 개인정보분쟁조정위원회에도 문의할 수 있습니다.

게임은 만 13세 이상을 대상으로 하며 아동을 주 대상으로 하지 않습니다. 아동의 개인정보를 의도적으로 수집하지 않습니다.

## 9. 보호 조치와 변경

게임은 개인정보를 수집·판매하지 않습니다. 기능이나 처리 항목이 바뀌면 방침과 필요한 스토어 고지를 갱신하고, 중요한 변경은 적용 법령에 따라 알립니다.
