# 머지 엔터프라이즈 개인정보처리방침

[English](en/)

- 최초 작성·적용: 2026년 10월 2일
- 공개 개발자: 릴리게임즈 / 운영 주체: 릴리에스앤씨
- 문의: <lilygames@lilysnc.com>
- 홈페이지: https://lilygames.lilysnc.com
- 서비스: 머지 엔터프라이즈: 장난감 공방 (Android 패키지: com.lilysnc.mergeenterprise)

## 1. 적용 범위

이 방침은 Google Play용 머지 엔터프라이즈 앱과 웹 버전(https://mergeenterprise.pages.dev)에 적용됩니다. 다른 게임 포털에 올라간 배포본에는 해당 포털의 방침도 함께 적용됩니다.

## 2. 게임 진행과 기기 저장

다음 정보를 기기에만 저장합니다.

- 공장 보드와 미션 진행
- 코인·보석·아이템
- 성장 레벨, 출석·과제·도감 기록
- 튜토리얼·안내 진행
- 언어·소리 설정
- 게임 오류 기록

앱은 앱 전용 저장소를, 웹은 브라우저 저장소(localStorage)를 사용합니다. 이 데이터는 서버로 전송되지 않으며 운영자가 볼 수 없습니다.

코인과 보석은 게임 안에서만 쓰는 재화이며, 현금으로 바꾸거나 결제하는 기능이 없습니다. 회원가입·로그인·실명·연락처가 필요하지 않습니다.

## 3. 광고·분석·서버

현재 배포본에는 광고 SDK, 분석 도구, 자체 서버, 리더보드, 결제가 없습니다. 앱은 게임 파일을 앱 안에 담고 있어 인터넷 없이도 실행됩니다. 광고·분석·결제를 추가하는 경우, 그 배포본을 출시하기 전에 이 방침과 스토어 고지를 먼저 갱신합니다.

## 4. 기기 기능과 권한

앱은 인터넷 권한 외의 권한을 요청하지 않으며 위치·연락처·사진·카메라·마이크에 접근하지 않습니다. 설정 화면의 개인정보처리방침 링크는 기기의 브라우저로 열립니다.

## 5. 처리 목적과 이용자 선택

기기 저장은 게임 진행을 이어가기 위한 것입니다. 설정 화면에서 언어와 소리를 바꿀 수 있습니다. 앱 데이터를 지우거나 앱을 삭제하면 저장된 진행이 모두 삭제됩니다. 웹 버전은 브라우저의 사이트 데이터를 지우면 삭제됩니다.

## 6. 제공자와 처리 위치

| 제공자 | 역할 |
| --- | --- |
| Google | Google Play 앱 배포, 문의 이메일 서비스 |
| Cloudflare | 웹 버전 배포(접속 보안·로그) |
| GitHub | 개인정보처리방침 페이지 호스팅 |

각 제공자의 글로벌 인프라에서 국외 처리가 발생할 수 있으며, 세부 사항은 해당 제공자의 정책을 따릅니다.

[Google 정책](https://policies.google.com/privacy) · [Cloudflare 정책](https://www.cloudflare.com/privacypolicy/) · [GitHub 정책](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)

## 7. 보유·삭제

기기 데이터는 이용자가 앱 데이터를 지우거나 앱을 삭제할 때까지 유지됩니다. 운영자는 게임 진행 데이터를 보관하지 않습니다. 문의 이메일은 문의 처리를 마친 뒤 30일 이내에 삭제하되, 법령상 보관 의무가 있으면 필요한 기간 동안 보관합니다.

## 8. 이용자 권리·아동

이용자는 적용 법령에 따라 열람, 정정, 삭제, 처리 제한, 동의 철회 권리를 행사할 수 있습니다. 문의는 위 이메일로 받으며 법정 기한 안에 처리합니다. 대한민국 개인정보침해 신고센터(118)와 개인정보분쟁조정위원회에도 문의할 수 있습니다.

게임은 만 13세 이상을 대상으로 하며 아동을 주 대상으로 하지 않습니다. 아동의 개인정보를 의도적으로 수집하지 않습니다.

## 9. 보호 조치와 변경

게임은 개인정보를 수집하거나 판매하지 않습니다. 기능이나 처리 항목이 바뀌면 이 방침과 필요한 스토어 고지를 갱신하고, 중요한 변경은 적용 법령에 따라 알립니다.
