## 1. 기본 원칙과 적용 범위

릴리에스앤씨(공개 개발자명 릴리게임즈, 이하 운영자)는 서비스의 정보 처리와 이용자 권리를 이 방침으로 안내합니다. 이 방침은 일반 웹, 앱인토스 미니앱, Google Play Android 배포본에 적용되며 기능이 없는 배포본에서는 해당 처리를 하지 않습니다.

서비스에는 실명 회원가입, 자체 로그인 화면, 공개 프로필, 채팅, 이용자 게시물 또는 클라우드 게임 진행 복원 기능이 없습니다. 앱인토스에서는 게임의 광고코인을 사용한 프로모션 조건에 따라 토스 포인트가 지급될 수 있습니다. 운영자는 은행 계좌·카드 번호를 직접 입력받지 않습니다.

## 3. 기기 안에 저장되는 정보

게임 진행과 광고 거래 복구 자료는 기기에 저장합니다. 월별 발행량 기능은 운영·테스트 환경을 분리한 통계용 자격, 최근 월 누계와 전송 확인 상태를 같은 진행 자료에 보관합니다. 이전에 갖고 있던 잔액을 신규 발행으로 다시 세지 않습니다.

발행량 서버에 게임 전체 저장 자료, 보유 잔액, 개별 터치·돼지 파괴 이력, 닉네임, 원본 SDK 오류, 광고 그룹 ID 또는 프로모션 코드를 보내지 않습니다. 첫 연습·실전에서 실제 적립한 조각의 월 누계만 전송하며, 기존 전송을 재시도해도 같은 누계가 다시 더해지지 않도록 처리합니다.

광고 재생 중에는 발행량 전송을 중단합니다. 통신 실패 시 게임·광고 보상은 계속 동작하고, 보관 기간 안의 미전송 누계는 안전한 시점이나 다음 실행에서 재시도합니다. 보관 기간이 지난 누계는 새 달 수량으로 바꾸지 않고 삭제합니다.

광고·분석 SDK는 동의 상태, 빈도 제어 값과 기기·세션 관련 가명 정보를 각자의 저장 영역에 둘 수 있습니다. Android 시스템 백업이 켜진 경우 기기 저장 자료가 이용자 본인의 Google 백업에 포함될 수 있으며 운영자는 그 개인 백업에 접근하지 않습니다.

- [Android 자동 백업 안내](https://developer.android.com/identity/data/autobackup)

## 4. 로컬 광고 진단과 이용자 선택 내보내기

로컬 광고 진단은 최근 최대 **200건·128KiB·24시간**으로 제한합니다. 원본 오류, URL, 광고 단위·플랫폼 사용자 식별자, 통계 인증 비밀 또는 재화 잔액은 진단 파일에 넣지 않습니다. 만료 자료는 실행 중 또는 다음 실행·조회에서 정리하며 앱이 종료된 동안에는 기기 정리 작업이 실행되지 않습니다.

진단 파일 전체를 자동 업로드하지 않습니다. 이용자가 설정의 개발자 진단에서 내보내기를 선택할 때만 다운로드, 토스 파일 저장·클립보드 또는 지원되는 기기 공유 기능을 이용합니다. 내보낸 파일·클립보드 사본은 앱의 자동 정리 대상이 아니므로 이용자가 직접 삭제해야 합니다. 문의에 자발적으로 첨부한 자료에는 제7조가 적용됩니다.

설정의 서버 연결 확인은 인증된 통신이 가능한지 점검하는 기능입니다. 이 점검 자체로 광고코인 발행량을 추가 전송하거나 게임 재화를 지급·차감하지 않습니다.

## 5. 광고와 앱인토스 프로모션

앱인토스 배포본은 토스가 제공하는 광고·분석·프로모션 SDK를 사용합니다. 토스는 자신의 서비스 안에서 광고 제공·측정과 포인트 지급을 처리합니다. 운영자는 게임에서 광고 완료·지급 성공/실패와 중복 처리 방지에 필요한 상태를 관리합니다. 앱인토스 배포본에는 외부 AdMob 플러그인이나 Firebase Analytics를 직접 연결하지 않습니다.

광고코인은 게임 내 재화이며 토스 포인트와 구분됩니다. 토스 포인트는 공지된 프로모션 조건을 충족하고 플랫폼 지급이 성공한 경우에만 지급됩니다. 광고코인의 보유만으로 현금 출금이나 지급을 보장하지 않습니다.

Google Play v0.7.0부터 Unity LevelPlay를 통한 보상형·배너 광고와 ironSource 광고 네트워크를 사용합니다. 이전 버전은 Google AdMob 보상형 광고를 사용합니다. 광고 사업자는 광고 제공·측정, 빈도 제어, 품질 관리, 진단과 부정 사용 방지를 위해 IP 주소, 대략적인 위치, 기기·앱·광고 상호작용, 진단 정보, 광고 식별자 및 App Set ID 등 기기 관련 식별자를 처리할 수 있습니다. LevelPlay SDK에 포함된 Ad Quality는 SDK 초기화와 함께 자동으로 초기화되며 광고 품질 및 노출·수익 측정 정보를 처리할 수 있습니다. 이는 운영자의 기기 내 광고 진단 파일과 별개이고, 해당 SDK가 처리하는 정보에는 사업자 정책이 적용됩니다. 앱은 LevelPlay에 실명·연락처·통계 서버 인증 자격을 제공하지 않습니다.

Google Play의 광고 보상은 게임 내 일반 코인이며 토스 포인트를 지급하지 않습니다. 홈 보상형 광고는 일반 코인30개, 광고코인 교환은 광고코인1개를 사용해 일반 코인50개를 받는 구조입니다. 적용 지역 및 배포 설정에 따라 개인정보 동의·선택 절차가 달라질 수 있습니다. 한국용 배포에서는 별도 GDPR 동의 화면을 표시하지 않는 설정일 수 있으며, 이를 이용자의 동의를 받았다는 의미로 처리하지 않습니다.

## 9. 보유·자동 삭제

### 광고코인 월별 집계

- **한국시간 기준 이번 달과 지난달, 최근 2개 달**만 보관합니다. 예를 들어10월에는9월·10월 자료를 보관하고11월1일부터9월 자료는 만료됩니다.
- 만료된 월의 기기별 누계와 서버 합계는 삭제하며, 같은 과거 자료를 다시 전송해도 새 발행으로 집계하지 않습니다.
- 운영자가 관리하는 백업은 만료된 월 자료가 남지 않도록 더 짧게 보관합니다. 만료 백업 정리는 주기적으로 수행하고, 삭제된 값이 영속 파일에 장기간 남지 않도록 월 변경 시 파일 재작성을 수행합니다.
- 기기에서는 실행·재개 시 보관 기간 밖의 전송 누계를 정리합니다. 기기 전원이 꺼졌거나 앱이 실행되지 않는 동안에는 기기 정리 작업을 할 수 없으며 다음 실행 때 적용합니다.
- 통계용 인증 자격은 현재 기기의 인증을 위해 기기에 보관하며 앱/기기 저장소 삭제 시 함께 없어질 수 있습니다. 서버에 별도 무기한 자격 원문 이력을 만들지 않습니다.

이 정책은 월별 집계 자료에 관한 것이며 **게임의 보유 코인·업그레이드·진행이나 필요한 광고 보상 복구 상태를 두 달마다 초기화하지 않습니다.** 이용자가 직접 내보내 관리 범위 밖에 보관한 사본은 이용자가 삭제해야 합니다.

### 그 밖의 자료

게임 진행·설정·거래 복구 기록은 해당 기기 저장소에 남으며, 로컬 광고 진단은 제4조의 별도 한도를 따릅니다. 이용자는 앱인토스 미니앱 삭제, Android 앱 데이터 삭제/앱 제거, 일반 웹 사이트 데이터 삭제 등 플랫폼이 제공하는 방법을 사용할 수 있습니다. 플랫폼 저장·백업의 구체적 삭제 동작은 해당 플랫폼 정책을 따릅니다.

## 10. 이용자 권리

이용자는 적용 법령에 따라 열람, 정정, 삭제, 처리 제한, 반대 또는 동의 철회에 관해 문의할 수 있습니다. 운영자는 문의를 확인하고 해당 자료의 식별 가능성과 법령상 의무에 따라 필요한 조치를 안내합니다. 문의 접수 후 영업일 기준7일 이내 회신을 목표로 하며 처리에 시간이 필요한 경우 그 사유를 안내합니다.

실명 계정과 연결하지 않는 기기 자료·가명 통계는 이메일 주소만으로 특정하기 어려울 수 있습니다. 필요한 최소 확인 방법을 별도로 안내하며, 인증 비밀을 공개 게시판이나 이메일로 보내도록 요구하지 않습니다. 기기 저장소 삭제로 자격을 잃은 경우에도 서버 월별 자료에는 자동 만료 정책이 적용됩니다. 광고·분석 사업자가 처리한 정보의 권리 행사는 해당 사업자의 절차도 이용할 수 있습니다.

개인정보보호위원회 또는 한국인터넷진흥원 개인정보침해 신고센터 등 관계 기관에 상담·신고할 수 있습니다.

## 11. 아동에 관한 안내

서비스는 아동을 주 대상으로 설계하지 않았으며 나이·생년월일을 직접 수집하지 않습니다. 만14세 미만 이용자는 법정대리인과 함께 서비스 및 기기·광고 개인정보 설정을 관리해야 합니다. 법정대리인 동의 없이 아동의 개인정보가 문의에 포함된 것을 확인하면 문의 처리에 필요한 경우를 제외하고 삭제합니다.

## 12. 안전성 확보 조치

- 클라이언트와 공개 API 사이에 HTTPS를 사용합니다. Cloudflare와 원본 서버 사이에는 별도 TLS를 사용하지 않으며 원본 직접 접근 제한·헤더 검증을 적용합니다.
- 관리자 권한과 기기별 통계 토큰을 분리하고 관리자 비밀을 게임 번들에 넣지 않습니다.
- 서버·DB 포트를 인터넷에 직접 공개하지 않고 월별 보관 한도·중복 방지·접근 제한을 적용합니다.
- 이름·연락처·계좌·카드 정보, 위치·사진·연락처·카메라·마이크 권한을 직접 요구하지 않습니다.
- 광고 재생 중 부수적인 발행량 전송을 중단하며, 분석·집계 실패를 게임 진행과 분리합니다.
