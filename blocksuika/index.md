# 보석만들기 개인정보처리방침

## 1. 적용 범위

이 방침은 웹, Google Play, App Store 및 앱인토스용 Gem Maker에 적용됩니다. 실제 데이터 흐름은 설치한 배포본과 플랫폼에 따라 다릅니다. 기존 문서의 ‘자체 서버·식별자·리더보드 없음’ 설명은 공통 리더보드 도입으로 변경되었습니다.

## 2. 게임 진행과 기기 저장

최고 점수, 판수, 코인·아이템, 일일 보상·스핀·광고 이용 기록, 보석 발견, 아이템 안내 확인, 언어·음량 설정을 기기에 저장합니다. 웹은 localStorage, 네이티브 앱은 앱 전용 저장소, 앱인토스는 SDK 저장소를 사용합니다. 이 진행 데이터 전체를 리더보드 서버에 복제하지 않습니다.

코인은 게임 내 재화이며 현금 환전 기능이 없습니다. 계정 비밀번호나 실명은 게임 실행에 필요하지 않습니다.

## 3. 공통 리더보드

리더보드 기능이 설정된 배포본은 시작 시 서버와 통신해 기기별 익명 참가자와 인증 세션을 생성하거나 복원합니다. 서버는 불투명한 참가자 ID와 복원 자격의 해시를 보관하며, 기기는 복원 자격을 저장합니다. 단기 인증 토큰은 실행 중 메모리에서 사용합니다. 익명 자격은 재실행 때 같은 참가자를 찾기 위한 것이며, 다른 기기·플랫폼의 설치를 자동으로 같은 사람으로 연결하지 않습니다.

**공개 등록은 선택 사항입니다.** BEST 갱신 시 등록할 닉네임·점수를 보여 주고 공개 동의를 확인한 뒤 전송합니다. 기존 로컬 BEST도 홈에서 별도 등록 여부를 묻습니다. 취소한 입력은 자동 제출하지 않습니다. 마지막으로 확인한 닉네임과 승인된 미완료 요청은 기기에 저장해 복원·재전송할 수 있습니다.

서버에 등록하는 정보는 닉네임, 점수, 참가자 ID, 규칙 버전, 요청/결과 식별자와 닉네임 변경 버전입니다. 공개 순위에는 닉네임·점수·순위 및 불투명 참가자 식별자 등이 포함됩니다. **닉네임에 실명·연락처 등 개인정보를 쓰지 마세요.** 복원 자격·토큰은 공개 순위에 노출하지 않습니다.

Gem Maker 서버는 steelball의 순위 데이터와 분리되어 있습니다. IP 주소는 접속 보안·요청 제한에 사용되며 프록시/서버 접속 로그에 처리될 수 있습니다. 점수·닉네임은 순위 제공과 중복/충돌 처리에 사용하며 광고 프로모션 현금 지급의 근거로 사용하지 않습니다.

## 4. 광고·분석·프로모션

- 웹: 현재 보상형 버튼은 외부 광고 없이 내부 시뮬레이션 보상을 제공합니다. Firebase Analytics를 조립하지 않습니다. 리더보드 API 통신은 별도입니다.
- Google Play/iOS용 코드: AdMob 광고와 Firebase Analytics 연결을 포함합니다. 해당 플랫폼 설정이 활성화된 배포본에서는 제공자가 광고 ID, IP로 추정하는 대략적 위치, 기기/앱 정보, 광고 상호작용 및 진단·분석 정보를 처리할 수 있습니다. iOS 광고 단위가 설정되지 않은 배포본에서는 광고를 표시하지 않습니다.
- 앱인토스: 토스 SDK 광고 및 플랫폼 이벤트 처리가 적용됩니다. 승인 전 테스트 배포본은 테스트 광고 ID를 사용합니다. 현재 프로모션 코드는 임시값이고 지급액은 0이므로 실제 프로모션 지급은 차단되어 있습니다.

광고·분석은 각 제공자의 정책과 플랫폼/지역 설정을 따릅니다. 게임은 위치·연락처·사진·카메라·마이크를 순위 등록에 요구하지 않습니다.

## 5. 처리 목적과 이용자 선택

진행 저장은 게임 제공, 익명 자격·세션은 참가자 복원과 인증, 요청 제한은 보안·남용 방지, 선택한 닉네임·점수 공개는 순위 서비스 제공 목적입니다. 적용 법령에 따라 서비스 이행, 공개 등록에 대한 이용자 동의, 보안 목적의 정당한 이익 등 적절한 근거를 적용합니다.

순위 공개를 거절해도 게임을 계속할 수 있습니다. 음량·언어는 게임 설정에서 바꿀 수 있습니다. 광고 관련 선택은 기기 및 해당 제공자의 설정을 참고하세요.

## 6. 제공자와 처리 위치

| 제공자 | 역할 |
|---|---|
| Cloudflare | 웹 배포, 리더보드 공개 HTTPS 프록시, 보안·접속 로그 |
| Oracle Cloud | 운영자의 별도 리더보드 API·데이터 저장 호스팅 |
| GitHub | 개인정보처리방침 페이지 호스팅 |
| Google | 해당 네이티브 배포본의 AdMob·Firebase, 문의 이메일 서비스 |
| 토스 | 앱인토스 저장·광고·플랫폼 기능 |

각 제공자의 글로벌 인프라에서 국외 처리가 발생할 수 있습니다. 세부 지역·보관 및 법적 이전 조치는 해당 제공자와 적용 계약·법령에 따릅니다. API 클라이언트는 공개 HTTPS를 사용합니다. 현재 Cloudflare에서 원본 서버로 가는 프록시 구간은 HTTP이며 종단간 TLS라고 표시하지 않습니다.

## 7. 보유·삭제·복구

기기 데이터는 사용자가 사이트/앱 데이터를 지울 때까지 유지됩니다. 서버 순위 기록에는 자동 만료가 적용되지 않으며 서비스 제공 기간 또는 삭제 요청 처리까지 보관합니다. 세션 토큰은 24시간 유효하고 요청 제한 데이터는 제한 구간에 따라 만료됩니다. 제공자 접속 로그·백업은 각 운영 정책을 따릅니다. 문의 이메일은 문의 처리 완료 후 30일 이내 삭제하되 법령상 보관 의무가 있는 경우 필요한 기간 보관합니다.

**기기 데이터를 지우거나 앱을 삭제해도 서버에 공개한 순위 기록은 자동 삭제되지 않습니다.** 서버 기록 열람·정정·삭제·공개 동의 철회는 lilygames@lilysnc.com으로 요청해 주세요. 닉네임·참가자 식별정보 등 필요한 최소 정보로 확인 절차를 안내합니다. 비밀번호·복원 자격·인증 토큰을 이메일로 보내지 마세요. 익명 복원 자격을 잃으면 이메일만으로 기록의 소유자를 확인하거나 복구하기 어려울 수 있습니다.

## 8. 이용자 권리·아동

이용자는 적용 법령에 따른 열람, 정정, 삭제, 처리 제한, 이동, 반대 및 동의 철회 권리를 행사할 수 있습니다. 문의는 위 이메일로 접수하며 적용 법정 기한 내 처리합니다. 대한민국 개인정보침해 신고센터(118), 개인정보분쟁조정위원회 또는 거주 국가 감독기관에도 문의할 수 있습니다.

게임은 만 13세 이상을 대상으로 하며 아동을 주 대상으로 하지 않습니다. 거주 지역의 동의 연령에 미달하는 이용자는 필요한 법정대리인 동의를 받아야 합니다. 아동의 불필요한 개인정보가 확인되면 적절한 삭제 조치를 취합니다.

## 9. 보호 조치와 변경

서버 인증 비밀은 게임 번들에 넣지 않고 복원 자격은 서버에서 해시로 처리합니다. 요청 크기·빈도·입력값을 검사하고 공개 순위 데이터와 자격을 분리합니다. 이러한 조치는 클라이언트 점수의 진위를 증명하는 것은 아닙니다. 개인정보를 판매하지 않습니다.

기능·처리 항목이 변경되면 방침과 필요한 스토어 고지를 갱신합니다. 중요한 변경은 적용 법령에 따라 알리고 필요한 경우 동의를 받습니다.
